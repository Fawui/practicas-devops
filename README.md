# Prácticas DevOps & Cloud — Roadmap 2026

Repositorio de prácticas, laboratorios, scripts y archivos de configuración desarrollados durante mi formación en Ingeniería DevOps y Cloud.

## Progreso del Plan de Estudio

- [ ] **01 - Git & Control de Versiones:** Flujos de trabajo, ramas, merge y resolución de conflictos.
- [ ] **02 - Linux & Bash Scripting:** Administración básica de sistemas, permisos, redes y automatización con scripts .sh.
- [ ] **03 - Python para Automatización:** Manejo de archivos, logs y consumo de APIs.
- [ ] **04 - Microsoft Azure Fundamentals (AZ-900):** Conceptos core de nube, redes, almacenamiento y seguridad.
- [ ] **05 - CI/CD con Azure DevOps:** Pipelines declarativos en YAML, integración y despliegue continuo.
- [ ] **06 - Docker:** Creación de Dockerfile, imágenes optimizadas, redes y docker-compose.
- [ ] **07 - Terraform (IaC):** Aprovisionamiento declarativo de infraestructura como código.
- [ ] **08 - Kubernetes:** Despliegue de pods, services, deployments y fundamentos de orquestación.

## Estructura del Repositorio

* /01-git — Notas y ejercicios de control de versiones.
* /02-linux-bash — Scripts de utilidad, monitoreo y tareas automatizadas en Bash.
* /03-python — Scripts de automatización en Python.
* /04-azure-pipelines — Ejemplos de pipelines YAML para CI/CD.
* /05-docker — Contenedores y aplicaciones multi-servicio con Docker Compose.
* /06-terraform — Configuraciones de infraestructura como código.
* /07-kubernetes — Manifiestos YAML de despliegue y servicios.
